# KNMI-snow-graphs
Data can be obtained from here https://daggegevens.knmi.nl/klimatologie/monv/reeksen

This script extracts the data in any downloaded zip files and plots it per weather station.

First a quick data exploration, second the amount of snow days during Christmas, and finally the average snow cover on average per year.

Snow info is sadly missing from the climate dashboard of the KNMI found here https://www.knmi.nl/klimaat#klimaatdashboard
